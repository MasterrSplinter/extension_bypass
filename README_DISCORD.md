Salut tout le monde ! 👋

Suite au message posté récemment ici : https://discord.com/channels/1235627362771664936/1512169413917409290 concernant les publicités intrusives sur le site de streaming **Webflix**, j'ai décidé de mettre les mains dans le cambouis ! 👨‍💻

J'ai développé **Webflix AdBlocker Pro**, une petite extension open-source optimisée spécialement pour contourner (bypass) toutes les publicités sur Webflix avant même qu'elles ne s'affichent sur les lecteurs vidéos. 🚀

✅ **Ultra-léger** (ne ralentit pas les vidéos)
✅ **Indétectable** (contourne les anti-adblocks de base)
✅ **Multi-plateformes** : Fonctionne sur PC (Chrome, Edge, Brave, Firefox) et sur mobile (via Kiwi Browser sur Android ou Orion sur iOS) !

Tout le guide d'installation (ça prend 2 minutes) est dispo sur mon GitHub :
🔗 **Lien du projet :** https://github.com/MasterrSplinter/extension_bypass

*(💡 Petite reco : pour une expérience ultime sans aucune pub sur tous les lecteurs, je vous conseille de coupler cette extension avec un bloqueur généraliste comme uBlock Origin !)*

N'hésitez pas à tester et à me faire vos retours. L'objectif est d'améliorer le code ensemble et, à l'avenir, de l'étendre à d'autres plateformes de streaming ! Bon visionnage à tous ! 🍿
